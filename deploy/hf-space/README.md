# Conecta+ — Painel de Expansão de Conectividade

Protótipo público do Conecta+, sistema de apoio à decisão para a expansão de fibra da Vivo, feito para o
Desafio IBM SkillsBuild & Fundação Telefônica Vivo. Código e documentação:
<https://github.com/RafaelSdeS/conecta-mais>.

Para começar: abra `/?uf=BA&semiarido=1&orcamento=150`, clique em **Abrir o painel**, pressione `Ctrl+K`, digite
"Juazeiro" e abra a ficha.

Esta é uma demonstração: as decisões registradas são compartilhadas entre visitantes e zeram quando o
Space reinicia, e as chamadas ao agente têm limite de uso.
